#Console_Daifugou_Game
## 🕹 遊び方
1. ゲームを開始するとカードが配られます。
2. 自分の番が来ると、手札が番号付きで表示されます。
3. 出したいカードの番号をスペース区切りで入力します（例: `0 1`）。
4. パスをする場合は、何も入力せずに Enter を押してください。

# Daifugo Core (CLI Edition)

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Console-lightgrey?style=for-the-badge)

Javaのオブジェクト指向設計をベースに構築された、コマンドラインで遊べる本格的な大富豪ゲームです。CPU3体を相手に、カードの強さや役を考慮した戦略的なプレイが楽しめます。

## 🃏 実装されているルール

本ゲームでは、大富豪の標準的なルールに加え、以下の特殊ルールが実装されています。

*   **複数枚出し**: 同じ数字のカードを同時に出すことができます（場の枚数と一致させる必要があります）。
*   **8切り**: 8を含むカードを出すと、その場で場が流れ、出した人のターンから再開します。
*   **11バック**: 11（J）を出すと、そのターン中のみカードの強さが一時的に逆転します。
*   **革命（拡張準備済み）**: システムレベルで強さの逆転ロジックをサポートしています。
*   **ジョーカー**: 最強の単体カードとして実装されています（強度：16）。

## 🚀 特徴

### 1. 柔軟なプレイヤークラス
`Player` 抽象クラスを継承することで、人間（`HumanPlayer`）とAI（`SimpleAI`）をシームレスに扱っています。AIは「弱いカードから優先的に出す」という基本的な思考アルゴリズムを持っています。

### 2. オブジェクト指向な設計
*   `Card`: ランク、スーツ、および大富豪特有の「強さ（3が最弱、2・Jokerが最強）」を管理。
*   `Table`: 場の状態（現在のカード、11バック中か、8切り発生かなど）をカプセル化。
*   `GameLogic`: カードが出せるかどうかの判定ルールを一括管理。

### 3. ストリームAPIの活用
Java 8以降の `Stream API` を使用し、手札のグループ化や出せるカードのフィルタリングを現代的かつ簡潔に記述しています。
